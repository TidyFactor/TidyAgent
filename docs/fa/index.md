## 🌟 نمای کلی و ارزش بنیادین

**Tidy** لایه عامل دستیار هوشمند مستقل است که بر بستر یک پایگاه‌داده محلی SQLite به عنوان منبع یگانه حقیقت (SSOT) دائمی فعالیت می‌کند.

### 🚀 شروع سریع

```bash
# دستیار تعاملی در ترمینال
tidy

# ثبت و بازیابی حافظه
tidy m "تصمیم معماری"
tidy q "SQLite"
```
