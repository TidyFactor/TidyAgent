# 🤖 الوكلاء الفرعيون ومحمل المهارات (Subagents & Skills-as-Agents)

تمتلك منصة Tidy بنية تحتية متقدمة لتوزيع المهام البرمجية المعقدة على **وكلاء فرعيين متخصصين (Specialized Subagents)**، مع دعم معيار **المهارات كوكلاء (Skills-as-Agents)** استناداً إلى مواصفات مهارات TidyFactor المعتمدة.

---

## 🎯 معمارية توزيع الوكلاء الفرعيين (`subagents.js`)

بدلاً من إرهاق وكيل الذكاء الاصطناعي الرئيسي بمحاولة حل المشكلة من الألف إلى الياء، تتيح وحدة `subagents.js` تفكيك المهام إلى أدوار متخصصة تعمل بشكل متوازٍ أو تسلسلي:

### الأدوار القياسية الجاهزة
1. **وكيل المعمارية والتصميم (`architect`)**:
   - تحليل متطلبات الأنظمة، فحص التعارضات، وتحديد مصفوفة الملفات المطلوب إنشاؤها أو تعديلها.
2. **وكيل التنفيذ البرمجي (`coder`)**:
   - كتابة الكود النظيف مع الالتزام بالمعايير الصارمة وبناء الاختبارات الوحدوية.
3. **وكيل التدقيق الأمني والجودة (`auditor`)**:
   - فحص الكود بعد كتابته للتحقق من عدم وجود تسريبات للمفاتيح السرية، أمان مدخلات المستخدم، وكفاءة استهلاك الذاكرة.
4. **وكيل التوثيق والتسليم (`documenter`)**:
   - صياغة توثيق Markdown متكامل بالعربية والإنجليزية وتحديث سجل التغييرات (`CHANGELOG.md`).

## 🧩 محمل المهارات القياسي (`skills-loader.js`)

تعتمد المنظومة معمارية `Skills-as-Agents`، حيث يُعتبر كل مجلد مهارة يحتوي على ملف `SKILL.md` بمثابة تعريف كامل لقدرات وكيل ذكي مستقل.

### معايير المهارة المتوافقة (15 Structural Rules)
يقوم محرك `skills-loader.js` بفحص والتحقق من صحة المهارات للتأكد من مطابقتها للقواعد:
- **ترويسة YAML الأمامية (Frontmatter)**: تحتوي على الاسم الدقيق، الوصف الإرشادي، وشروط التفعيل والموانع (`Anti-triggers`).
- **العزل الجغرافي والسياقي**: المهارات لا تتدخل في نطاقات خارج اختصاصها.
- **التوافق ثنائي اللغة (Bilingual Support)**: جاهزية التفاعل باللغتين العربية والإنجليزية.

```yaml
---
name: tidyfactor-php-kernel
description: Domain-agnostic PHP Kernel modular monolith engine (Flight + Medoo + Plates).
triggers:
  - kernel
  - modules
  - plugins
anti_triggers:
  - react
  - vue
---
```

## 📋 مخلّق ملخصات المهام الذكي (`brief-generator.js`)

عند استدعاء أمر `tidy brief <task-id>`، يقوم المحرك بتجميع كل ما يحتاجه الوكيل الفرعي لتنفيذ المهمة في مستند موجه فائق التركيز (Autonomous Task Brief):

```markdown
# 🎯 موجز المهمة البرمجية: TASK-104

## 📌 السياق والهدف
- **المهمة**: ترقية محرك بحث FTS5 ليدعم الترتيب المخصص لمعامل التلاشي.
- **النطاق المستهدف**: `@tidy/core`
- **الملفات المتأثرة**: `packages/core/src/db.js`, `packages/core/src/memory.js`

## 🛡️ القواعد الحاكمة (Sovereign Invariants)
- ممنوع كسر التوافق العكسي مع `node bin/tidy.js`.
- الحفاظ على معايير `PRAGMA synchronous = NORMAL`.

## 🧪 خطة التحقق والاختبار (Verification Plan)
- تشغيل: `npm test` للتأكد من نجاح كافة سيناريوهات الذاكرة.
```

يسمح هذا الملخص المدمج لأي وكيل ذكاء اصطناعي (Claude Code, Antigravity, Cursor) ببدء العمل فوراً دون إضاعة وقته في تحليل الملفات غير ذات الصلة.

---

## ⚡ الاستدعاء عبر الطرفية

```bash
# إنشاء ملخص مهمة ذكي لوكيل المطورين
tidy brief 14 --format markdown

# سرد المهارات والوكلاء المتاحين في النظام
tidy skills list
```
