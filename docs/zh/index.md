## 🌟 概述与核心价值

**Tidy** 是一个独立的个人助理层，直接在单一本地 SQLite 数据库上运行，并将其作为永久的唯一真实可信来源（SSOT）。

### 🚀 快速上手

```bash
# 启动交互式终端向导
tidy

# 记录与搜索记忆
tidy m "架构决策记录"
tidy q "SQLite"
```
