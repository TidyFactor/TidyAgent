# 🏢 حزمة الأعمال والمكتب السيادي (@tidy/office)

حزمة `@tidy/office` هي نظام إدارة أعمال متكامل وسيادي (Sovereign Business Suite)، مدمج داخل منظومة Tidy. صُممت خصيصاً للمطورين المستقلين (Freelancers)، رواد الأعمال، والوكالات التقنية الصغيرة لإدارة العملاء، الفواتير، المصروفات، والتدفقات النقدية محلياً بالكامل وبأعلى درجات الخصوصية.

---

## 🌟 المبادئ التأسيسية لحزمة Office

1. **السيادة التامة للبيانات (Zero-Cloud Leakage)**:
   - كافة سجلات العملاء والفواتير والمصروفات محفوظة في قاعدة SQLite المحلية (`~/.tidy/tidy.db`).
2. **عزل المعاملات المالية (Financial Integrity)**:
   - استخدام المعاملات الذرية (`db.transaction()`) لضمان عدم حدوث تكرار أو فقدان للبيانات.
3. **توليد ملفات إلكترونية ومستندات قياسية**:
   - إمكانية إصدار الفواتير وعروض الأسعار بصيغ JSON قياسية، Markdown، وHTML جاهزة للطباعة والتصدير كـ PDF.
4. **التكامل مع PocketOffice**:
   - محول استيراد مدمج متوافق مع بنية ملفات PocketOffice JSON (`clients.json`, `invoices.json`).

## 📦 الوحدات الوظيفية الرئيسية

### 1. إدارة علاقات العملاء (CRM Lite)
سجل عملاء متطور يتيح تتبع جهات الاتصال، الشركات، الصفقات المفتوحة، والقيمة العمرية المتوقعة للعميل (LTV).

#### الحقول والبيانات
- `name`: اسم العميل أو جهة الاتصال.
- `company`: اسم الشركة أو المؤسسة.
- `email`: البريد الإلكتروني المعتمد.
- `phone`: رقم الهاتف أو الواتساب.
- `status`: حالة العميل (`lead`, `prospect`, `active`, `churned`).
- `currency`: العملة الأساسية للمعاملات (`USD`, `EGP`, `SAR`, `EUR`).
- `notes`: ملف دلالي وملخص متطلبات العميل.

#### أوامر الطرفية
```bash
# إضافة عميل جديد
tidy office crm add --name "شركة الأفق التقني" --company "Al-Ufuq" --email "info@alufuq.com" --currency "USD"

# استعراض العملاء النشطين
tidy office crm list --status active

# الحصول على ملخص ملف العميل (Client Dossier)
tidy office crm show 1
```

---

### 2. منشئ الفواتير والتحصيل (Invoice Builder)
إصدار ومتابعة الفواتير الاحترافية مع حساب تلقائي للضرائب، الخصومات، والبنود الفرعية، مع تتبع مواعيد الاستحقاق والمدفوعات المتأخرة.

#### هيكل بنود الفاتورة
- تفاصيل الخدمات بالساعة أو بالمشروع (`line_items`).
- حساب نسبة ضريبة القيمة المضافة (`tax_rate`).
- شروط السداد وحسابات الإيداع البنكية أو المحافظ الرقمية.

#### أوامر الطرفية
```bash
# إنشاء مسودة فاتورة لعميل
tidy office invoice create --client-id 1 --due-in 14

# إضافة بند خدمات للفاتورة
tidy office invoice add-item 101 --description "تطوير تكامل بروتوكول MCP" --qty 40 --rate 75

# اعتماد الفاتورة وتغيير حالتها إلى صادرة
tidy office invoice issue 101

# تسجيل دفعة مستلمة للفاتورة
tidy office invoice pay 101 --amount 3000 --method "wire"
```

---

### 3. متتبع المصروفات والتكاليف (Expense Tracker)
تسجيل التكاليف التشغيلية، اشتراكات الخوادم، تكاليف واجهات الـ API (مثل OpenAI وAnthropic)، ونفقات التسويق، مع ربطها مباشرة بمشاريع أو عملاء محددين.

#### أوامر الطرفية
```bash
# تسجيل مصروف خوادم
tidy office expense add --title "استضافة Hetzner Cloud" --amount 45.50 --currency USD --category "infra"

# تسجيل تكلفة اشتراك API ذكاء اصطناعي
tidy office expense add --title "Gemini & Claude API tokens" --amount 120.00 --category "ai-services"
```

---

### 4. لوحة التدفق النقدي وصافي الأرباح (Cashflow & Profit Analytics)
تحليل لحظي يجمع إجمالي الدخل المحصل، المبالغ المعلقة، والمصروفات خلال فترات زمنية مخصصة، لإعطاء صورة واقعية دقيقة عن السيولة النقدية.

```bash
# استعراض التقرير المالي للربع الحالي
tidy office cashflow --period "Q3-2026"
```

## 🤖 الاستدعاء والتحكم عبر بروتوكول MCP

تتيح أدوات MCP في `@tidy/mcp` لوكلاء الذكاء الاصطناعي في محررك إدارة أعمالك برمجياً وبشكل موثوق:

| أداة MCP | الوظيفة |
|---|---|
| `tidy_office_crm` | إضافة، بحث، وتحديث بيانات العملاء وسجل المعاملات |
| `tidy_office_invoice` | إنشاء مسودات الفواتير، حساب الإجماليات، وإصدار ملفات الدفع |
| `tidy_office_expense` | تصنيف النفقات وحساب التكاليف لكل مشروع |
| `tidy_office_cashflow` | تقديم ملخص مالي فوري وشامل لتدفقات الأموال والضرائب |

## 🔄 استيراد البيانات من PocketOffice

إذا كنت تستخدم سابقاً PocketOffice OS المعتمد على ملفات JSON المسطحة:

```bash
# استيراد كافة العملاء والفواتير تلقائياً إلى قاعدة SQLite
tidy office import-pocket --path "c:/wamp64/www/PocketOffice/resources/app/data"
```
يقوم الأمر بالتحقق من صحة المخطط (Schema Validation)، منع تكرار المعرفات، وترقية البيانات فوراً إلى جداول SQLite المؤمّنة بـ WAL.
