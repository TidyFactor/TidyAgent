# 📝 تطبيقات الإنتاجية الدقيقة (Productivity Micro-Apps)

يضم محرك Tidy في نواته السيادية (`@tidy/core`) أربعة تطبيقات إنتاجية دقيقة وموجهة للمطورين والمهندسين. صُممت هذه التطبيقات لتكون بدائل محلية، فائقة السرعة، وخالية من أي اشتراكات سحابية، مع التخزين المباشر في قاعدة بيانات SQLite المحلية (`~/.tidy/tidy.db`).

---

## ⚡ الميزات المشتركة للتطبيقات

1. **ارتباط تلقائي بحلقة الذاكرة (Autonomous Memory Loop)**:
   - كل مهمة، قصاصة برمجية، يومية، أو سر يتم تسجيله يمكن فهرسته اختيارياً وتمريره كعقدة معرفية إلى الذاكرة الدائمة (`nodes`).
2. **محرك بحث نصي كامل ومتقدم (FTS5 BM25)**:
   - استرجاع فوري بالكلمات المفتاحية والرموز دون الحاجة لفتح واجهات ثقيلة.
3. **أمان محلي وسيادة كاملة (Local-First Sovereign)**:
   - لا توجد سحابة وسيطة، بياناتك ملكك بنسبة 100%.

---

## 1. إدارة المهام الذكية (`tasks`)

أداة بسيطة ولكنها خارقة لإدارة المهام أثناء البرمجة دون مغادرة الطرفية أو بيئة التطوير.

### الحقول الأساسية
- `title`: عنوان المهمة.
- `priority`: الأولوية (`low`, `medium`, `high`, `urgent`).
- `category`: التصنيف (مثل: `core`, `docs`, `finance`, `bug`).
- `status`: الحالة (`pending`, `in_progress`, `completed`, `cancelled`).
- `due_date`: تاريخ الاستحقاق.

### استخدام الطرفية (CLI)
```bash
# إضافة مهمة سريعة
tidy task "مراجعة عقود تكامل MCP مع Claude Code" --priority high --category core

# عرض المهام المعلقة
tidy tasks

# تعليم مهمة كمكتملة (مع تحويلها اختياريًا إلى ذاكرة منجزة)
tidy task done 12
```

### استخدام بروتوكول MCP في الـ IDE
عبر مساعدك الذكي في Antigravity أو Cursor:
- استدعاء أداة `tidy_tasks_add` لإسناد مهام جديدة تلقائياً أثناء المحادثة.
- فحص المصدر الحي `tidy://tasks/pending` للتحقق مما يجب إنجازه تالياً.

## 2. مدير القصاصات البرمجية (`snippets`)

خزينة برمجية سريعة لحفظ الأوامر المعقدة، إعدادات Docker، استعلامات SQL، وأكواد الـ Regex مع تمييز لغة البرمجة والعلامات الدلالية.

### الحقول الأساسية
- `title`: اسم القصاصة أو الغرض منها.
- `language`: لغة البرمجة (مثل: `bash`, `sql`, `javascript`, `dockerfile`).
- `content`: محتوى الكود أو الأمر البرمجي.
- `tags`: وسوم البحث والتصنيف (مفصولة بفواصل).

### استخدام الطرفية (CLI)
```bash
# إضافة قصاصة جديدة
tidy snippet add --title "Docker Compose WAL SQLite" --lang yaml --tags "docker,sqlite,wal"

# البحث في القصاصات
tidy snippet find "sqlite wal"

# نسخ أو استعراض القصاصة
tidy snippet get 4
```

## 3. يوميات المطور والقرارات (`journal`)

سجل زمني لتدوين الملاحظات الهندسية، قرارات التصميم المعماري (ADRs)، وتسجيل ملخصات الجلسات اليومية لمزامنتها مع الذاكرة العميقة.

### الحقول الأساسية
- `entry`: نص اليومية أو ملخص جلسة العمل.
- `mood`: تقييم الحالة المزاجية أو طاقة التركيز (`focused`, `challenging`, `productive`, `tired`).
- `tags`: وسوم الموضوعات المرتبطة.

### استخدام الطرفية (CLI)
```bash
# تدوين ملخص نهاية اليوم
tidy journal "أكملنا اليوم توثيق مكتبة @tidy/office وربطنا محرك البحث FTS5 بمحرك VitePress" --mood focused --tags "docs,office"

# استعراض آخر الملاحظات
tidy journal list --limit 5
```

## 4. الخزينة الآمنة للمفاتيح والملاحظات المشفرة (`vault`)

مساحة محلية آمنة لحفظ الرموز السرية، مفاتيح التطوير المحلية (`LOCAL_API_KEY`)، وملاحظات التكوين الحساسة على جهازك الشخصي بعيداً عن ملفات الـ Git المستودعة.

### الخصائص
- لا تُرفع المفاتيح إطلاقاً خارج نطاق جهازك.
- لا تظهر في سجلات استعلامات MCP العامة إلا بطلب صريح ومحدد بالاسم.

### استخدام الطرفية (CLI)
```bash
# حفظ قيمة سرية في الخزينة
tidy vault set STRIPE_TEST_KEY "sk_test_51Mz..."

# استرجاع قيمة مفتاح
tidy vault get STRIPE_TEST_KEY

# سرد المفاتيح المسجلة دون كشف أسرارها
tidy vault list
```

## 🔗 التكامل المتبادل مع النواة `@tidy/core`

تتكامل هذه الميكرو-تطبيقات برمجياً داخل مشاريع Node.js الخاصة بك مباشرة عبر الاستيراد السهل:

```javascript
import { db, tasks, snippets, journal, vault } from '@tidy/core';

// إضافة مهمة برمجياً
const taskId = tasks.create({
  title: 'Audit SQLite WAL checkpointing',
  priority: 'high',
  category: 'core'
});

// تدوين يومية مهندس
journal.log('Memory cache hit ratio improved by 34% after PRAGMA tuning.');
```
