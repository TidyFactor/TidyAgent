# 🔌 خادم بروتوكول سياق النموذج (Stdio MCP Server)

يوفر **Tidy** خادم Stdio مدمج يعمل وفق معيار **Model Context Protocol (MCP)** الإصدار JSON-RPC 2.0، مما يمكن وكلاء الذكاء الاصطناعي (مثل Google Antigravity، Claude Code، Cursor، و Windsurf) من التفاعل المباشر مع ذاكرتك الدائمة، مهامك، وحزمة أعمالك المكتبية دون أي وسطاء سحابيين.

---

## ⚙️ إعداد الخادم في محررات الأكواد (IDE Setup)

أضف تكوين الخادم التالي إلى ملف إعدادات الـ MCP الخاص بمحررك (مثل `mcp_config.json` أو إعدادات Claude Desktop):

```json
{
  "mcpServers": {
    "tidy": {
      "command": "node",
      "args": ["/path/to/tidy-agent/packages/mcp/src/server.js"],
      "env": {
        "NODE_ENV": "production"
      }
    }
  }
}
```

## 🛠️ قائمة الأدوات الذكية المتاحة (40 أداة MCP متخصصة)

### 1. أدوات الذاكرة والسياق والطبقة الحاكمة (Memory, Context & Control Plane)
* **`tidy_recall`**: استرجاع الذكريات والقرارات المعمارية عبر محرك FTS5 BM25 وحساب الاضمحلال المعرفي.
* **`tidy_memorize`**: تخزين عقدة ذاكرة دائمة جديدة في الـ SSOT.
* **`tidy_get_context`**: قراءة السياق النشط حالياً وجدار الحماية المعرفي.
* **`tidy_switch_context`**: التبديل الذري بين سياقات العمل (`dev`, `marketing`, `personal`).
* **`tidy_whoami`**: فحص هوية المساعد، المجال النشط، وحالة قاعدة البيانات.
* **`tidy_context_compile`**: تجميع سياق منضبط تحت سقف التوكنات عبر 5 طبقات للموجهات البرمجية.
* **`tidy_intent_route`**: تحليل نوايا التعليمات وترشيح المهارات المناسبة مع فرض سقف 2-3 مهارات كحد أقصى.
* **`tidy_taxonomy_classify`**: تصنيف الذاكرة وقرارات الكود ضمن تاكسونومي الذاكرة الـ 8 المعياري.

### 2. أدوات المهام وسرب الوكلاء المتعددين (Tasks & Parallel Swarm)
* **`tidy_task_add`**: إضافة مهمة جديدة إلى قائمة المهام المحلية مع تكليف وكيل متخصص.
* **`tidy_task_list`**: استعلام وتصفية المهام حسب الحالة (`pending`, `completed`) والمجال.
* **`tidy_exec_subagent`**: تفويض مهمة إلى أحد الوكلاء الفرعيين (`planner`, `coder`, `researcher`, `qwen`, إلخ).
* **`tidy_parallel_dispatch`**: تشغيل سرب الوكلاء المتعددين بالتوازي في بيئات معزولة مع فض النزاعات آلياً.
* **`tidy_list_skills`**: اكتشاف واستعراض مهارات مجتمع TidyFactor المثبتة.
* **`tidy_synthesize_brief`**: توليد موجز مهام ماركداون ذاتي الاكتفاء (Self-Contained Task Brief).
* **`tidy_db_stats`**: استعراض إحصائيات سعة التخزين، حجم ملف الـ WAL، وعدد السجلات.

### 3. محرك العقل السيادي وحصاد المعارف (Sovereign Brain & Harvester)
* **`tidy_doctor`**: فحص شامل لصحة قاعدة بيانات SQLite، نمط WAL، وسلامة ملفات المعرفة.
* **`tidy_search`**: بحث هجين موحد يجمع بين قاعدة البيانات وملفات الماركداون للطبقات الأربع.
* **`tidy_extract`**: استخراج عناصر المعرفة الذرية (KI) مع فرض قيود النفي والمزامنة اللحظية.
* **`tidy_transcripts`**: مسح جنائي لمحادثات الوكلاء السابقة واستخراج المعلومات دون إرهاق السياق.
* **`tidy_hygiene`**: تدقيق مساحات التخزين ومجلدات الجلسات المؤقتة مع تفعيل وضع المعاينة الآمنة.
* **`tidy_firewall`**: جدار حماية صارم يمنع تسرب السياق بين أوضاع العمل المتعارضة.
* **`tidy_manifest`**: فحص وثيقة المهارة والتحقق من التزامها بقواعد منظومة Tidy الـ 15.
* **`tidy_harvest_scan`**: مسح بيئات عمل الوكلاء ومجلدات المعارف السابقة واكتشاف عناصر الذاكرة المرشحة.
* **`tidy_harvest_read`**: قراءة متدفقة لوثيقة المعرفة الكاملة مع تحليل ترويسة YAML وبيانات السطور.
* **`tidy_harvest_import`**: استيراد ذري جماعي لعناصر الذاكرة في قاعدة البيانات مع تحديث فهارس FTS5.

### 4. الحوكمة والإعدادات (Governance & Configuration)
* **`tidy_config_get`**: قراءة الإعدادات النظامية المحفوظة في قاعدة البيانات.
* **`tidy_config_set`**: تحديث الإعدادات والقيم التشغيلية وتخصيص بيئة العمل.
* **`tidy_profile_update`**: تخصيص بروفايل المستخدم ونبرة التخاطب والعملة واللغة المفضلة.
* **`tidy_govern_rules`**: إدارة وتحديث قواعد الجدار الناري وسياسات التخزين المؤقت.

### 5. أدوات حزمة إدارة الأعمال والمكتب التجاري (`@tidy/office`)
* **`tidy_crm_list`**: استعلام خط أنابيب العملاء وحالات الصفقات والميزانيات.
* **`tidy_crm_add`**: تسجيل بطاقة عميل تجاري B2B جديد في المنظومة.
* **`tidy_invoice_list`**: استعلام كشف الفواتير حسب الحالة والعميل.
* **`tidy_invoice_create`**: إصدار فاتورة مجزأة مع احتساب الضريبة والخصومات آلياً.
* **`tidy_cashflow_summary`**: كشف لحظي للأرباح والخسائر والتدفق المالي (P&L Telemetry).
* **`tidy_client_dossier`**: تجميع ملف العميل الاستخباراتي الشامل من الفواتير والذاكرة المشتركة.

### 6. عروض الأسعار والمنتجات ومحرك تصدير مستندات PDF (Proposals & PDF Export)
* **`tidy_proposal_create`**: إنشاء عرض سعر تجاري مجزأ مرتبط بالعميل وجدول الدفعات ونطاق العمل.
* **`tidy_proposal_list`**: استعراض وإدارة عروض الأسعار المسجلة ومراحل اعتمادها.
* **`tidy_product_list`**: استعراض كتالوج المنتجات والخدمات وأسعارها ووحدات القياس.
* **`tidy_product_upsert`**: إضافة أو تحديث منتج أو خدمة في كتالوج التسعير السيادي.
* **`tidy_document_export`**: تصدير فوري للفواتير وعروض الأسعار إلى مستندات PDF أو HTML بـ 4 ثيمات راقية (Modern, Minimal, Luxury, Corporate).

## 📡 الموارد الحية الديناميكية (9 Dynamic MCP Resources)

تتيح الموارد الحية لوكلاء الذكاء الاصطناعي قراءة حالة النظام اللحظية باستمرار دون استدعاء أدوات:

| مسار المورد (URI) | الاسم | الوصف الفني |
|---|---|---|
| `tidy://profile` | **الملف الحاكم (Profile)** | هوية المستخدم، اللغة، ونبرة المساعد المستمرة (Ring 0). |
| `tidy://context/current` | **السياق النشط (Current Context)** | قيود الجدار الناري والمجال المعرفي النشط (Ring 1). |
| `tidy://tasks/pending` | **طابور المهام المعلقة (Pending Tasks)** | قائمة المهام ذات الأولوية التي تنتظر التنفيذ. |
| `tidy://brain/doctor` | **فحص صحة النظام (System Doctor)** | تقرير الفحص التشخيصي المباشر لصحة قاعدة البيانات وسلامة النواة. |
| `tidy://brain/taxonomy` | **تاكسونومي المعارف (Taxonomy)** | فهرس تصنيف المعارف عبر الطبقات الأربع. |
| `tidy://brain/hygiene` | **تقرير النظافة والتخزين (Hygiene)** | تفصيل استهلاك مساحات التخزين وخيارات التنظيف الآمن. |
| `tidy://office/cashflow` | **كشف السيولة المالي (Live Cashflow)** | ملخص السيولة المالية وصافي الأرباح المحققة لحظياً. |
| `tidy://config` | **إعدادات النظام (System Config)** | لقطة فورية من إعدادات النظام الحاكمة. |
| `tidy://govern` | **قواعد الحوكمة (Governance)** | سياسات وقواعد الجدار الناري وحوكمة البيانات. |
