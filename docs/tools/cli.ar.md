# 🛠️ مرجع أوامر سطر الأوامر الشامل (CLI Reference)

يوفر محرك الطرفية في **Tidy** مجموعة متكاملة من الأوامر فائقة السرعة والمصممة لتسهيل عمل المطورين واسترجاع وتخزين المعرفة في ثوانٍ معدودة.

---

## ⚡ 1. أوامر التطوير السريعة (Developer One-Liners)

أوامر خفيفة بحرف واحد أو كلمة واحدة للاستخدام اليومي المستمر دون إبطاء سير العمل:

### البحث الفوري في الذاكرة (`tidy q`)
يبحث في نصوص الذاكرة المفهرسة عبر FTS5 BM25 مع تطبيق خوارزمية الاضمحلال المعرفي ونجوم الأهمية:
```bash
# بحث ذكي سريع
tidy q "WAL mode"

# تجاوز الجدار الناري للبحث في كل المجالات (تسويق، شخصي، تطوير)
tidy q "auth tokens" --bypass
```

### التقاط وحفظ فكرة أو قرار لحظياً (`tidy m`)
تسجيل قرار معماري أو معلومة تقنية في ثانية واحدة مباشرة إلى قاعدة البيانات مع تحديد الفئة والأهمية:
```bash
# حفظ قرار معماري بأهمية قصوى (5 نجوم)
tidy m "استخدام نمط WAL لرفع تزامن قراءات SQLite" --cat decision --imp 5

# حفظ قاعدة عمل برمجية في مجال التطوير
tidy m "كافة مسارات الـ API يجب أن تبدأ بـ /v1" --cat rule --domain dev
```

### إدارة المهام السريعة وحلقة التغذية الراجعة (`tidy task` & `tidy done`)
إضافة مهمة جديدة مع تحديد الوكيل المخصص لها، وإغلاقها بأرشفة تلقائية للقرار في الذاكرة:
```bash
# إضافة مهمة جديدة وتكليف وكيل المبرمج بها
tidy task "تطبيق نظام المصادقة عبر JWT" --priority urgent --agent coder

# عرض قائمة المهام المعلقة
tidy tasks --pending

# إتمام المهمة مع أرشفة النتيجة تلقائياً في ذاكرة الـ SSOT!
tidy done tsk_a7b8c9 --result "تم استخدام RS256 مع تدوير المفاتيح أسبوعياً"
```

### كشف حالة الجدار الناري والسياق النشط (`tidy who`)
فحص فوري لهوية النظام، المجال النشط، وعدد عناصر الذاكرة:
```bash
tidy who
```

## 🧠 2. محرك إدارة الذاكرة السيادية (`tidy memory`)

| الأمر | الخيارات | الوصف والوظيفة |
|---|---|---|
| `tidy memory save "<نص>"` | `--cat`, `--imp`, `--domain`, `--tier` | حفظ عقدة ذاكرة مع التحكم بالطبقة (core, project, session, ephemeral). |
| `tidy memory recall "<بحث>"` | `--limit`, `--bypass` | استرجاع أفضل النتائج المطابقة مرتبة حسب حساب النقاط الرياضية. |
| `tidy memory list` | `--tier`, `--domain`, `--limit` | عرض جدول نصوص الذاكرة المخزنة مع معدل اضمحلالها. |
| `tidy memory forget <id>` | — | حذف عقدة ذاكرة ومزامنة فهارس FTS5 فوراً. |
| `tidy memory prune` | `--days <N>` | تطهير الذكريات المؤقتة القديمة بأمان دون المساس بذاكرة الـ Core. |

## 💼 3. أوامر حزمة إدارة الأعمال (`@tidy/office`)

تتكامل هذه الأوامر مع حزمة `@tidy/office` لإدارة شؤون المكتب والمبيعات:

### إدارة العملاء والصفقات (CRM)
```bash
# استعراض قائمة العملاء وحالة الصفقات
tidy crm list

# تسجيل عميل جديد مع الميزانية المتوقعة
tidy crm add --name "شركة القمة للتجارة" --budget 45000 --status prospect --contact "أحمد محمود"
```

### الفواتير المحسوبة آلياً (Invoicing)
```bash
# عرض قائمة الفواتير وحالات السداد
tidy invoice list

# إنشاء فاتورة مجزأة مع احتساب الضريبة تلقائياً
tidy invoice create --client cli_xxxx --tax 14 --items '[{"name":"تطوير بوابة دفع","qty":1,"unitPrice":12000}]'

# تسجيل سداد فاتورة رسمياً
tidy invoice pay inv_yyyy
```

### المصروفات وكشف التدفق النقدي (Cashflow)
```bash
# تسجيل مصروف تشغيلي جديد
tidy expense add --title "خوادم سحابية Hetzner" --amount 180 --category hosting

# طباعة كشف التدفق المالي والأرباح والخسائر اللحظي (P&L Telemetry)
tidy cashflow
```

### تجميع ملف العميل الاستخباراتي (AI Client Dossier)
يقوم بدمج بيانات الـ CRM، كشف الفواتير، وعقود الذاكرة التاريخية في ملف تنفيذي شامل بضغطة زر:
```bash
tidy dossier cli_xxxx
```

## 📦 4. سيادة البيانات والتصدير والاستيراد (Portability)

نظام Tidy يضمن عدم احتجاز بياناتك (Zero Vendor Lock-in):

```bash
# تصدير كامل الذاكرة إلى مجلد متوافق مع نظام Obsidian PARA
tidy export --out ./my_obsidian_vault

# تصدير لقطة ذرية بصيغة JSON للأرشفة والنقل
tidy export --format json --out ./tidy_snapshot.json

# استيراد وقراءة ملاحظات ماركداون خارجية وفهرستها فوراً
tidy import ./external_notes/

# ترقية واستيراد بيانات PocketOffice السابقة بضغطة زر
tidy import-pocketoffice --source ./PocketOffice-Data/
```

## 🛡️ 5. فحص وصيانة قاعدة البيانات (DB Health)

```bash
# تنفيذ دمج قسري لملف الـ WAL مع قاعدة البيانات الرئيسية
tidy checkpoint

# فحص سلامة وتماسك الجداول (PRAGMA integrity_check)
tidy integrity

# إنشاء نسخة احتياطية مشفرة فورية لقاعدة البيانات
tidy backup
```
