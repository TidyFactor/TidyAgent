# 🚀 البدء السريع وتثبيت المنظومة (Getting Started)

أهلاً بك في منظومة **تايدي (Tidy Ecosystem)** — نظام المساعد الشخصي وإدارة الأعمال السيادية المبني حول قاعدة بيانات SQLite محلية كـ **مصدر وحيد للحقيقة (Single Source of Truth - SSOT)**.

---

## 💻 متطلبات التشغيل الأساسية

تم تصميم Tidy ليعمل بكفاءة فائقة وبأقل متطلبات برمجية ممكنة دون أي ارتهان بأي خدمات سحابية:

* **بيئة التشغيل**: Node.js بإصدار `>= 22.0.0` (يعتمد النظام على وحدة `node:sqlite` المدمجة افتراضياً دون الحاجة لأي مجمعات C++ أو أدوات `node-gyp`).
* **أنظمة التشغيل المدعومة**: 
  - Windows 10 / 11 (مع دعم شاشة الـ HUD الطافية بالاختصار `Alt+Space`).
  - macOS (Apple Silicon & Intel x64).
  - Linux (Ubuntu, Debian, Fedora, Arch).
* **حجم النظام**: أقل من 50 ميغابايت بالكامل.

---

## ⚡ التثبيت والإعداد في 3 خطوات

### 1. استنساخ المستودع والدخول للمجلد
```bash
git clone https://github.com/TidyFactor/TidyAgent.git tidy-agent
cd tidy-agent
```

### 2. تثبيت الحزم الفرعية المعتمدة
```bash
npm install
```

### 3. التهيئة الصامتة وقاعدة البيانات (Zero-Config Bootstrap)
يعتمد النظام على التهيئة الذاتية الفورية؛ بمجرد تشغيل أي أمر، سيقوم النظام تلقائياً بإنشاء قاعدة البيانات في المسار الافتراضي `~/.tidy/tidy.db`:

```bash
# تهيئة صامتة وفحص سلامة النظام
node bin/tidy.js init

# أو عبر المعالج التفاعلي المرئي
node bin/tidy.js ui
```

## 🧭 واجهات التفاعل الثلاث (Tidy Surfaces)

توفر المنظومة 3 طرق رئيسية للوصول إلى أدواتك وبياناتك بنفس قاعدة البيانات المتزامنة لحظياً بنمط WAL:

| الواجهة | طريقة التشغيل | الاستخدام الأمثل |
|---|---|---|
| **سطر الأوامر (CLI)** | `node bin/tidy.js` أو `npm run cli` | المطورون، كتابة الأوامر السريعة في ثوانٍ، وسكربتات الأتمتة. |
| **خادم الذكاء الاصطناعي (MCP)** | `npm run mcp` | الوكلاء الأذكياء في محررات الكود (Antigravity, Cursor, Claude Code). |
| **تطبيق سطح المكتب (Desktop HUD)** | `npm run desktop` | الواجهة المرئية الشاملة، شاشة المتابعة اللحظية، وإدارة الـ CRM والفواتير. |
| **لوحة إدارة الويب (Web Console)** | `npm run web` | تصفح المنظومة عبر المتصفح على المنفذ المحلي `http://localhost:3840`. |

## 🔒 التحقق من بيئة العمل وحوكمة الذاكرة

يمكنك دائماً في أي وقت فحص سياق العمل النشط، حالة قاعدة البيانات، وحالة الجدار الناري عبر الأمر:

```bash
node bin/tidy.js who
```
