# 📸 Tidy Studio — Desktop Screenshots Gallery (Dual-Locale)

## Directory Architecture

- **`./` (Root)** & **`en/`**: English (LTR) Interface Screenshots — Used in the primary root `README.md`, `apps/desktop/README.md`, and international documentation.
- **`ar/`**: Native Arabic (RTL) Interface Screenshots — Used in `docs/i18n/README.ar.md`, `docs/apps/desktop-app.ar.md`, and `docs/user_manual.ar.md`.
