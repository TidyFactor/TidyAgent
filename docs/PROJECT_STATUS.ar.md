## 🎯 2. خارطة ومسارات التطوير المعتمدة وفق ترقيم SemVer

### 📦 `v1.4.3` — مركز الحوكمة والإعدادات (The Central Nervous System) ✅ [مكتمل]
- إدارة مركزية لمتغيرات النظام وقواعد الجدران النارية (`system_config`).
- تحكم دقيق في الملف الشخصي: الاسم، الدور، الثيم، العملة، واللغة.
- تكامل تام عبر CLI, MCP (`tidy_config_*`, `tidy_profile_update`), وواجهات Tidy Studio.

### 📦 `v1.4.4` — استوديو المهارات والوكلاء الشامل (Universal Skills & Agents Studio) ✅ [مكتمل]
- ماسح دلائل المهارات والوكلاء عبر كافة الأدوات: Claude Code, Cursor, Codex, Windsurf, Copilot, Antigravity/Gemini.
- محرر كود مدمج Monospaced مع حفظ لحظي وتزامن AST لبيانات الـ YAML.
- مجموعات ووسوم غير مدمرة داخل SQLite SSOT دون المساس بالملفات المصدرية على القرص.
- مدقق الامتثال لقواعد TidyFactor الـ 15 وتوليد القوالب التأسيسية.

### 📦 `v1.4.5` — استوديو حاصد المعرفة واستخراج أدمغة الوكلاء (Knowledge Harvester Studio) ✅ [مكتمل]
- استكشاف ذاتي لمصادر المعرفة (`~/.gemini/knowledge/**`، خطط وجلسات Antigravity Brain، قواعد Cursor وقواعد Gemini).
- واجهة استعراض رئيسية-تفصيلية (2-Pane Studio) مع معاينة Markdown حية وترشيح للحالات.
- استيراد ذري تجميعي (Atomic Batch Import) إلى ذاكرة SQLite SSOT مع الفهرسة اللحظية FTS5 BM25.
- تكامل مباشر "Open in Studio" للتحرير الفوري.
