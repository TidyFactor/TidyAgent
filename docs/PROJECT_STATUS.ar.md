### 📦 `v1.5.0` — محرك Tidy Sovereign Brain MCP الشامل (البديل السيادي الكامل لـ brain mcp) 🎯 [الهدف النشط الحالي]
الترقية الجوهرية لخادم `@tidy/mcp` والنواة ليصبح البديل السيادي الكامل وغير القابل للمنافسة لخادم `tidyfactor-brain` MCP القديم:
1. **فحص صحة النظام الشامل (`tidy_doctor` / `doctor`)**: فحص متكامل لقاعدة بيانات SQLite SSOT، حالة WAL، فهرس FTS5، تعداد عناصر المعرفة عبر المستويات الأربعة، المساحة التخزينية، والمهارات المسجلة.
2. **البحث المعرفي الهجين رباعي المستويات (`tidy_search_knowledge_base` / `search_knowledge_base`)**: دمج البحث في ذاكرة SQLite مع البحث المباشر في عناصر معرفة القرص (`~/.gemini/knowledge/**`) مع التصفية بنطاقات المستويات الأربعة (`global`, `tech`, `projects`, `session`).
3. **استخراج وحفظ عناصر المعرفة الذرية (`tidy_extract_knowledge_item` / `extract_knowledge_item`)**: إنشاء وحفظ عناصر KI ذرية بصيغة Markdown قياسية مع قيود سلبية إلزامية (Negative Constraints) وكتابتها على القرص وفهرستها لحظياً داخل SQLite FTS5.
4. **ماسح المحادثات والجلسات الجنائي (`tidy_recall_transcripts` / `recall_transcripts`)**: استرجاع القرارات وسجلات الجلسات التاريخية (`brain/**/transcript.jsonl`) عند الطلب دون إغراق نافذة السياق.
5. **مراقب النظافة التخزينية والتطهير (`tidy_storage_hygiene` / `audit_storage_hygiene`)**: فحص وتنظيف استهلاك القرص لتسجيلات الفيديو والجلسات ومجلدات التخزين المؤقت مع حماية المعاينة التجريبية (`--dry-run`).
6. **مدقق التلوث والجدار الناري للسياق (`tidy_check_firewall` / `check_contextual_firewall`)**: التحقق اللحظي من عدم تسرب مصطلحات التسويق إلى سياقات البرمجة أو العكس.
7. **مفتش بيانات المهارات التفصيلي (`tidy_get_skill_manifest` / `get_skill_manifest`)**: قراءة وتدقيق تفاصيل المهارة وأوامرها ونقاط فحص القواعد الـ 15.
8. **مولد الملخصات الصوتية التفاعلية (`tidy_audio_overview` / `generate_audio_overview`)**: توليد حوار إذاعي ثنائي المضيفين بأسلوب NotebookLM حول أي موضوع أو قرار تقني.
9. **طبقة التوافق العكسي التام (Zero-Breaking Compatibility Layer)**: دعم أسماء الأدوات الأصلية والبديلة لتشغيل أي وكيل أو بيئة مبرمجة على `brain mcp` دون أي تعديل.
