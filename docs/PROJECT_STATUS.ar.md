## 🎯 2. خارطة ومسارات التطوير المعتمدة وفق ترقيم SemVer

### 📦 `v1.4.3` — مركز الحوكمة والإعدادات (The Central Nervous System) 🎯 [الإصدار القادم المباشر]
- مركز مركزي لحفظ وإدارة متغيرات التطبيق عبر النواة (`system_config`).
- إدارة الحساب والملف الشخصي (Profile): الاسم، الدور، والتفضيلات الكاملة.
- تفضيلات الواجهة والتشغيل: اللغة (AR/EN مع دعم كامل لـ RTL)، الثيم (Dark/Light/System)، العملة، والتنسيقات.
- الربط الحي مع CLI، خادم MCP، وواجهة Tidy Studio.

### 📦 `v1.4.4` — لوحة إدارة المهام الاحترافية (Task Board v2)
- واجهة كانبان وقوائم متطورة بالسحب والإفلات وتغيير الحالات بسلاسة.
- الفرز والتصفية الذكية حسب الأولوية ومجالات العمل (Domain Firewall).
- إسناد المهام للوكلاء الفرعيين (`@planner`, `@coder`, `@researcher`, `@scribe`).
- حلقة تحويل المهام المكتملة تلقائياً إلى قرارات بالذاكرة (Autonomous Task-to-Memory Loop).

### 📦 `v1.4.5` — الذاكرة المعرفية، البحث المتقدم ومحرر النصوص الاحترافي
- محرر Markdown ونصوص متكامل مع تمييز الأكواد البرمجية (Syntax Highlighting) والمعاينة اللحظية والحفظ التلقائي.
- ترقية استعلامات FTS5 BM25 وفلاتر البحث الهجين لاستكشاف الذاكرة بدقة.

### 📦 `v1.4.6` — مركز الوكلاء وإدارة المهارات (Agents & Skills Hub — Full CRUD)
- إدارة كاملة (إنشاء، قراءة، تعديل، حذف) للوكلاء الفرعيين والوكلاء المخصصين.
- تخصيص الـ System Prompts، الصلاحيات، وجدران الحماية لكل وكيل.
- إدارة وفحص المهارات (Skills) والتحقق من مطابقتها للقواعد الـ 15.

### 📦 `v1.4.7` — ترسيخ التطبيقات الإنتاجية الأساسية
- **مكتبة الأكواد (Snippets Vault)**: وسوم لغات البرمجة، تصفية سريعة، ونسخ بضغطة زر.
- **سجل اليوميات والتأملات (Journal)**: خط زمني تفاعلي مرتبط بالذاكرة والأنشطة.
- **الخزنة والمفاتيح السرية (Vault)**: تشفير محلي AES-GCM، إخفاء تلقائي، وحماية سيادية من التسريب.

### 📦 `v1.4.8` — مساحات العمل وتعدد قواعد البيانات ومركز النسخ الاحتياطي
- إضافة، تعديل، وتبديل مساحات العمل (Workspaces) وعزل السياقات.
- دعم تعدد قواعد بيانات SQLite والتبديل الحي بين القواعد (`Switch Active SSOT`).
- مركز النسخ الاحتياطي الفوري (`VACUUM INTO`) والاستعادة مع فحص السلامة (Checksums).
- تصدير واستيراد بصيغة JSON SSOT ومجلدات Obsidian PARA Markdown.

### 📦 `v1.4.9` — سجلات التدقيق ومدير الإضافات (Audit Logs & Plugin Manager)
- سجلات تدقيق النظام اللحظية (System Operations, Subagent Invocations & Security Events).
- إطار عمل تسجيل وتشغيل وتوسيع الإضافات والتطبيقات الخارجية (Plugin Lifecycle).

### 📦 `v1.4.10` — مركز خدمات ونماذج الذكاء الاصطناعي (AI Provider Center)
- **إدارة BYOK**: دعم ومراقبة استهلاك ومفاتيح OpenAI, Anthropic, Gemini, DeepSeek, Groq.
- **إدارة النماذج المحلية (Local AI)**: تشغيل محلي 100% عبر Ollama, LM Studio, Llama.cpp بدون إنترنت.
- توجيه النماذج (Model Routing) وحساب تكلفة الرموز وطبقات الإخفاق الاحتياطية (Fallback Tiers).

### 🏁 `v1.5.0` — إطلاق نظام التشغيل المعرفي المتكامل (Tidy Cognitive OS Milestone)
- دمج كافة المكونات، اختبارات الحمل والانحدار الشاملة عبر CLI و MCP وسطح المكتب والويب.
- توثيق موحد عبر كافة اللغات مع تثبيت الإصدار المستقر للنواة.
