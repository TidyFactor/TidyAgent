## 🎯 2. أولويات ومسارات التطوير المعتمدة حالياً (المرحلة الثالثة: خدمات النواة والحوكمة)

### 🏛️ المحور الأول: النواة كمنصة خدمات مشتركة (Core as OS Platform)
1. **مركز الحوكمة والإعدادات (Settings & Governance Engine)**:
   - مركز مركزي لإدارة وحفظ المتغيرات الخاصة بالتطبيق (`system_config`).
   - إدارة متكاملة للحساب (Profile): الاسم، الدور، التفضيلات (اللغة AR/EN، الثيم، العملة، التوقيت).
2. **إدارة مساحات العمل وتعدد قواعد البيانات (Multi-Workspace & Multi-DB)**:
   - واجهة ومحرك لإضافة وإدارة مساحات العمل وعزل السياقات.
   - إمكانية إنشاء قواعد بيانات SQLite جديدة والتبديل الحي بينها.
3. **مركز النسخ الاحتياطي والنقل (Backup, Export & Import)**:
   - أخذ نسخ احتياطية فورية (Snapshots) واستعادتها.
   - تصدير واستيراد بصيغة JSON SSOT ومجلدات Obsidian PARA Markdown.
4. **مركز سجلات النظام والتشخيص (Audit & Logs Center)**:
   - سجلات العمليات، أحداث الأمان، واستدعاءات الوكلاء.
5. **مركز إدارة الإضافات (Plugin Manager)**:
   - إطار عمل لتسجيل وتشغيل وتوسيع التطبيقات الإضافية بمرونة عبر خدمات النواة.

### 🧠 المحور الثاني: الذاكرة الذكية والتحرير المتقدم
1. **تحرير متقدم للنصوص (Advanced Markdown Editor)**:
   - محرر نصوص غني مع تمييز الصيغ البرمجية والحفظ التلقائي والمعاينة اللحظية.
2. **محرك بحث وتحسين الذاكرة**:
   - ترقية استعلامات FTS5 BM25 وفلاتر التقييم والتصنيف المتقدم.

### 📋 المحور الثالث: إدارة المهام والوكلاء
1. **لوحة إدارة المهام الاحترافية v2 (Task Board)**:
   - واجهة كانبان وقوائم تفاعلية مع السحب والإفلات.
   - ربط المهام المكتملة تلقائياً بالذاكرة وتفويض الوكلاء الفرعيين.
2. **مركز الوكلاء والمهارات (Agents & Skills Hub - Full CRUD)**:
   - إدارة الوكلاء الفرعيين (`@planner`, `@coder`, `@researcher`, `@scribe` والوكلاء المخصصين).
   - إدارة وتفعيل واختبار المهارات (Skills) مع تعيين جدران الحماية لكل وكيل.

### 🤖 المحور الرابع: مركز خدمات الذكاء الاصطناعي (AI Hub)
1. **إدارة مفاتيح النماذج الخارجية (BYOK)**:
   - دعم وإدارة مفاتيح OpenAI, Anthropic, Gemini, DeepSeek, Groq.
2. **إدارة النماذج المحلية (Local AI)**:
   - تكامل مع Ollama, LM Studio, Llama.cpp لتشغيل الذكاء الاصطناعي محلياً بدون إنترنت وسيادياً 100%.

### 📦 المحور الخامس: ترسيخ التطبيقات الإنتاجية الأساسية
1. **مكتبة الأكواد (Snippets)**: تصنيف، وسوم لغات البرمجة، ونسخ بضغطة زر.
2. **سجل اليوميات والتأملات (Journal)**: خط زمني تفاعلي وربط بالذاكرة.
3. **الخزنة والمفاتيح السرية (Vault)**: تشفير محلي AES-GCM، إخفاء المفاتيح، وحماية ضد التسريب.
