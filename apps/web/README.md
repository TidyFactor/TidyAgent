# @tidy/web

Web Management Console for **Tidy**.
Zero external dependencies — built natively with Node.js `node:http`.

## Features
- **RESTful API**: Instant JSON endpoints for memories, tasks, subagents, and stats.
- **Shared Visual UI**: Serves the identical, luxury management dashboard as the Electron desktop app.
- **Port**: Runs on `http://localhost:3840` by default.

## Run
```bash
npm start
# Server starts at http://localhost:3840
```
